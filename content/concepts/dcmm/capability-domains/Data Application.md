> [!abstract] DCMM 能力域 / Capability Domain
> [[DCMM]] 九大能力域之一。数据应用流通面向内部应用和外部流通释放数据价值。

## 定义

围绕内部数据应用、外部数据管理、数据开放和数据服务建立可持续机制，在安全合规的前提下提升数据利用效率并实现业务、经济或社会价值。

## 能力边界

- **负责**：数据使用场景、外部数据引入、开放利用和服务化供给。
- **不替代**：数据资产价值评估、数据安全审查或具体分析产品开发。

## 能力项 Capability Items

| 能力项                                                                      | 核心目标                                               |
| --------------------------------------------------------------------------- | ------------------------------------------------------ |
| [[frameworks/dcmm/capability-items/Data Application\|数据应用]]             | 以业务场景为牵引，将数据用于分析、决策、运营和创新     |
| [[frameworks/dcmm/capability-items/External Data Management\|外部数据管理]] | 对外部数据的引入、授权、质量、使用和退出进行全过程管理 |
| [[frameworks/dcmm/capability-items/Data Open\|数据开放]]                    | 面向符合条件的对象提供可发现、可获取、可理解的数据     |
| [[frameworks/dcmm/capability-items/Data Service\|数据服务]]                 | 将数据能力封装为稳定、可管理、可度量的服务             |

## 建设要点

1. 建立场景发现、价值评估、优先级和效果复盘机制。
2. 对外部数据供应方、授权范围、质量和持续可用性进行管理。
3. 建立数据开放目录、申请审批、交付和使用反馈机制。
4. 对数据服务实施目录、契约、版本、服务水平和成本管理。

## 典型产出

- 数据应用场景地图、产品清单和价值评估报告
- 外部数据目录、授权合同、供应方评价和退出记录
- 数据开放目录、申请审批记录与使用成效报告
- 数据服务目录、接口契约、SLA 与运营指标

## 自评问题

- 数据应用是否有明确用户、业务目标和可量化成效？
- 外部数据是否具备合法来源、明确授权和退出机制？
- 开放与服务过程是否兼顾可用性、安全、成本和持续运营？
